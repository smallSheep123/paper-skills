# Academic Clean

**学术简约 / Paper-faithful**

> 目标：像研究者自己认真整理过的 slides，而不是模板网站或 AI 卡片。

关键词：**克制、可信、清楚、论文一致、可讲、可复核**。

适合：

- 论文组会 / paper reading；
- 学位答辩、开题、内部技术评审；
- 8–15 分钟学术汇报；
- 用户明确要求“正式、简约、别太花”。

它是一套**视觉语言**，不是固定 PPT 模板。

## 1. 视觉语言

### 色彩

- 内容页优先白底或极浅灰白；
- 主色通常只选深蓝、深青、深灰中的一种；
- 强调色只用于关键数字、当前模块、重要箭头或结论词；
- 绝大多数层级由排版、留白、字号和线条建立。

默认避免：

- 强渐变；
- 发光；
- 厚阴影；
- 玻璃拟态；
- 大面积装饰色块。

### 字体

常用起点：

- 中文：Microsoft YaHei；
- 英文 / 数字：Arial；
- 标题：28–32 pt；
- 正文：18–22 pt；
- 图注 / 来源：12–14 pt。

真正标准仍然是实际投影可读。

### 网格

- 左右边距约 0.6–0.75 英寸；
- 维持少量稳定对齐线；
- 一页通常不超过两个主要列区；
- 不把四宫格、六卡片当默认布局。

## 2. 页面优先级

常见表达从优先到次优：

1. 单主图 + 一条解释线；
2. 左机制图 / 右论文图；
3. 大论文图 + 就地标注；
4. 上下结构：结论 / 证据；
5. 流程图 + 少量文字；
6. 必要的公式 / 表格。

每页都应有清楚的主视觉焦点。

## 3. 标题

优先使用有信息量的标题：

- 生命周期分布漂移使静态分组快速失效
- 在线放置只能减缓债务，无法修复历史错误

如果必须使用“研究动机 / 系统设计”这类章节标题，就用副标题或页面结论补出真正的 message。

## 4. 论文图

Clean 最重视论文一致性。

允许：

- 裁掉无关空白；
- 拆分多子图；
- 放大当前重点；
- 增加 1–3 个讲解层箭头 / 编号 / 高亮；
- 将复杂 Figure 分多页讲。

避免：

- 给论文图套圆角、投影或设备壳；
- 把折线图改成商业信息图；
- 为统一配色擅自改变论文曲线颜色；
- 为“完整”把所有子图都缩小塞进一页。

## 5. 文字密度

页面文字是**讲述路标**，不是讲稿。

通常：

- 2–5 个短句 / 标签；
- 一个说明块 1–2 行；
- 超过 3 行的段落优先重组或拆页。

不要默认做“背景 / 方法 / 结果”三张大卡片。

## 6. 公式与方法

公式只保留理解方法所必需的部分。

方法步骤优先表达为：

```text
输入 → 关键变换 → 输出
```

复杂推导、长伪代码放备注或备份页。

## 7. 结果页

- 一张主结果图通常占 50–70% 页面注意力；
- 旁边只保留 1–2 条真正重要的 takeaway；
- 大数字只强调会改变结论理解的结果；
- 图多时拆页，不做四张图等宽堆叠。

## 8. 封面与结尾

### 封面

保留：

- 论文题目 / 系统名；
- 作者、机构、会议；
- 报告人。

可以有深色纯底和小型论文元素，但不放“3 个贡献点卡片”。

### 结尾

优先：

- 3 条以内的结论链；
- 局限 / future work；
- 一句明确收束。

除非用户要求，不需要用整页 “THANK YOU” 消耗主线时间。

## 9. Clean 审阅问题

视觉模型应能回答：

- 第一眼是否知道这页在讲什么？
- 论文证据是不是主角？
- 是否为了“好看”改变了论文含义？
- 正文和图中文字是否真的可读？
- 是否出现模板化卡片和无意义装饰？
- 页面是否比原论文 Figure 更容易讲？
