# Academic Rich

**学术丰富 / Conference-editorial**

> 目标：有高质量学术演讲的叙事感和页面节奏，但仍然保持研究可信度。

关键词：**叙事、层次、视觉锚点、非对称、节奏、专业**。

适合：

- 课程展示；
- 公开技术分享；
- 10–30 分钟演讲；
- 跨领域听众；
- 用户明确要求“更好看、更丰富、更有演示感”。

它不是：

- 咨询公司 pitch deck；
- 产品发布会；
- 海报式堆图；
- AI 插画展。

它也是一套**视觉语言**，不是固定 PPT 模板。

## 1. 色彩与字体

允许：

- 1 个主色；
- 1 个辅助色；
- 1 个强调色；
- 少量浅色区域背景；
- 章节页深底；
- 极轻的渐层或纹理。

前提是这些元素服务空间层级，而不是为了效果。

论文图优先保留原始视觉编码；自绘机制图再使用 deck 色系。

字体仍保持克制：

- 中文优先 Microsoft YaHei；
- 英文 / 数字优先 Arial；
- 标题约 30–36 pt；
- 正文约 18–22 pt；
- 大数字约 28–44 pt。

## 2. 构图

Rich 可以更主动使用：

- 60/40 非对称双栏；
- 70% 大图 + 30% 解释；
- 全宽主图 + 就地注释；
- 章节页 / 问题页；
- 大数字 + 图表；
- 时间线；
- before / after；
- overview → zoom-in 连续两页。

但**一页仍只有一个主要 message**。

## 3. 丰富来自节奏，不是塞更多东西

可以在整套中交替：

1. 问题页：大标题 + 留白；
2. 解释页：自绘机制；
3. 证据页：大论文图；
4. 对比页：before / after；
5. 方法页：结构图 + 当前模块聚焦；
6. 结果页：主图 + 大数字；
7. 收束页：一句结论 + 少量证据。

不要连续五页复制同一种双栏，也不要为了“每页不一样”强行变版式。

## 4. 视觉锚点

每页至少有一个明显的视觉锚点：

- 论文主图；
- 系统架构局部；
- 自绘流程；
- 关键数字；
- 一句关键问题；
- 概念性图形。

它应承担约一半以上的注意力，而不是和五六个同级元素竞争。

## 5. 论文图的演讲化处理

Rich 可以更积极地编辑 Figure：

- 拆多子图；
- 灰化非重点区域；
- 高亮当前区域；
- 旁边增加教学简化图；
- 用编号建立阅读顺序；
- 同一 Figure 连续做 overview → zoom-in。

讲解层和数据层必须视觉上可区分。

不能改变实验数据含义。

## 6. 自绘图

视觉 AI 可以主动提出：

- 因果链；
- 数据流；
- 组件关系；
- 机制流程；
- 概念对比；
- 读图路径。

优先使用简单几何图形、箭头和短标签，保持可编辑和学术感。

## 7. 生成式图片

只在少数情况下考虑：

- 封面抽象主题；
- 非证据性的章节转场；
- 自绘几何仍难以表达的直觉隐喻。

必须让观众明确知道它不是论文数据或真实系统截图。

## 8. 富而不乱

默认限制：

- 单页主要视觉组尽量 ≤ 7；
- 正文段落通常不超过 3 行；
- 卡片只有在真的需要分组时才出现；
- 阴影极轻或不用；
- 圆角不是默认语法；
- icon 只有在减少文字时才有价值；
- 图形、色块、照片不要同时争夺主视觉。

## 9. Rich 审阅问题

视觉模型应能回答：

- 页面是否“丰富但不商业”？
- 是否存在清楚的视觉锚点？
- 观众 3 秒内能否找到阅读顺序？
- 页面变化是否服务叙事？
- 自绘解释和论文证据是否区分清楚？
- 是否出现夸张渐变、玻璃卡片、装饰 icon？
- 结果页是否仍然以数据为主角？
