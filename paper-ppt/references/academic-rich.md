# Academic Rich：学术丰富 / Conference-editorial

## 1. 目标

做出“高质量学术演讲 / 顶会 keynote / 研究团队公开 talk”的演示感，**更丰富但仍然像学术 PPT**。

关键词：**叙事、层次、构图、视觉锚点、节奏、专业**。

适用：
- 课程展示 / 公开技术分享
- 10–30 分钟演讲
- 用户明确说“好看一点、丰富一点、排版高级、有演示感”
- 需要把复杂论文讲给跨领域听众

它不是：
- 咨询公司 pitch deck
- 互联网产品发布会
- 海报式堆图
- AI 生成插画展

## 2. 视觉语法

### 色彩

- 允许 1 个主色 + 1 个辅助色 + 1 个强调色。
- 可以有浅色区域背景、章节页深底、局部反白。
- 允许非常轻的渐层或纹理，但只能服务空间层级，不能成为“效果”本身。
- 图表配色优先尊重论文；自绘结构图采用 deck 色系。

### 字体

- 中文仍优先 Microsoft YaHei，英文/数字 Arial，保证可移植。
- 标题 30–36pt，正文 16–21pt，大数字 28–44pt。
- 可通过字重、字号、少量大小写变化制造编辑感，不靠多字体。

### 构图

允许更强的非对称与编辑式布局：
- 60/40 非对称双栏
- 70% 大图 + 30% 解释
- 全宽主图 + 浮动注释
- 章节页 / 过渡页
- 大数字 + 图表
- 时间线 / 流程 / before-after
- 局部裁切 + 放大镜式细节（不用真的画放大镜图标也可以）

但一页仍只有一个核心 message。

## 3. 页面节奏

Rich 的“丰富”来自**页与页之间的节奏变化**，不是单页塞更多东西。

建议交替：
1. 章节/问题页 —— 大标题 + 大留白
2. 解释页 —— 自绘机制图
3. 证据页 —— 大论文图
4. 对比页 —— before / after
5. 方法页 —— 结构图 + 局部强调
6. 结果页 —— 主图 + 大数字
7. 收束页 —— 一句话 + 3 个以内结论

不要连续 5 页相同双栏。

## 4. 视觉锚点

每页至少有一个占明显面积的视觉锚点：
- 论文主图
- 系统架构局部
- 自绘流程
- 关键数字
- 一句问题
- 概念性图形

视觉锚点通常占 45–70% 的注意力。

## 5. 论文图 + 编辑式讲解

Rich 允许对论文 Figure 做更积极的“演讲化处理”：
- 把一张 Figure 的 4 个子图分两页讲。
- 先灰化非重点区域，再高亮当前讲解区域。
- 将论文图旁边配一个简化后的机制图。
- 用编号与短标签建立读图顺序。
- 对同一图做“overview → zoom-in”连续两页。

仍然禁止改变实验数据含义。

## 6. 自绘图与视觉 AI

视觉 AI 可以主动提出：
- 系统机制示意图
- 因果链
- 数据流
- 组件关系
- 概念对比
- 读图路径

这些图应由简单几何图形、箭头、标签构成，保证可编辑和学术感。

AI 生成的写实/插画图片只在以下情况考虑：
- 封面抽象主题
- 非证据性的章节转场
- 论文场景需要一个“直觉隐喻”且自绘几何图表达不清

若使用，必须与实验图明确区分，不能让观众误以为是论文数据或真实系统截图。

## 7. Rich 风格常用页面原型

### A. Hero Figure
大图占 2/3，另一侧只放一句结论 + 2 个标注。

### B. Annotated Architecture
架构图放大，当前模块高亮，其他模块降噪；下方给一句“为什么重要”。

### C. Problem → Mechanism
左侧真实问题/论文现象，右侧自绘机制，中间用一个逻辑箭头连接。

### D. Before / After
旧方法与新方法并排，视觉元素一一对应，避免两套完全不同的图。

### E. Data Story
上方一句结论；中间主图；底部只放“解释这条曲线为什么发生”的 1–2 个因果句。

### F. Section Break
深色纯底，大标题 + 1 个抽象图形 / 论文局部元素。控制在整套 deck 的 10–20%。

## 8. 富而不乱的限制

- 单页视觉对象建议 ≤7 个主要组。
- 正文段落仍不超过 3 行。
- 卡片最多偶尔出现 2–3 个，且必须真有分组意义；不能每页卡片化。
- 阴影只能极轻，默认不用。
- 圆角不是默认语法。
- icon 只在能减少文字时使用；不要用 icon 做装饰阵列。
- 图形、色块、照片不能同时抢主视觉。

## 9. Rich 风格视觉验收

视觉模型需要明确回答：
- 页面是否“丰富但不商业”？
- 是否存在一个清晰视觉锚点？
- 观众 3 秒能否找到阅读顺序？
- 视觉变化是否服务叙事，而不是为了每页不一样？
- 自绘图与论文证据是否区分清楚？
- 有没有夸张渐变、玻璃卡片、装饰 icon、海报化文字？
- 结果页是否仍然以数据为主角？
