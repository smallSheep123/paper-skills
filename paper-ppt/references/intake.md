# 开工前访谈：问题库与话术

> SKILL.md §0 的展开。目标：**用最少的来回，拿到会改变成品的全部信息**。
> 原则：能从材料推断的不问；会改变结果的必问；每个问题都带默认值；一条消息最多 5–6 问。

---

## 1. 通用问题库（按优先级）

| 优先级 | 维度 | 问法（中文） | 默认 | 回答如何改变成品 |
|:-:|---|---|---|---|
| P0 | 场景 | 这次是组会读论文、讲自己的论文、答辩/开题/中期、课程展示，还是工作汇报？ | 组会读论文 | 页序模板、封面写法、是否有“启发/成果”页 |
| P0 | 时长 / 详略 | 要讲多久，或大概多少页？（简略约 10 页 8–10 分钟 / 详细约 18–20 页 15–20 分钟） | 详细版 | 页数、方法拆几页、实验放几页 |
| P0 | 听众 | 听众是同方向、同领域不同方向，还是外行/评委？ | 同领域不同方向 | 背景页数量、术语解释、公式保留多少 |
| P0 | 语言 | PPT 和演讲备注用什么语言？ | 与提问语言一致 | 风格方言、字体、标题写法 |
| P1 | 风格 | 有想用的风格吗？可以说预设名、发截图、给学校/组里模板，或让我推荐。 | 按场景推荐 | 视觉语言、预设选择 |
| P1 | 重点 | 最希望听众记住的一件事是什么？哪部分要讲细、哪部分可以略？ | 按论文贡献平均 | 篇幅分配、备份页 |
| P1 | 讲者身份 | 你是论文作者，还是读这篇论文来分享？ | 读者 | “我们/作者”的用法，封面署名，个人观点页 |
| P1 | 放映环境 | 在哪台电脑放？自己的、会场 Windows、Mac，还是只交 PDF？ | 会场 Windows | 字体策略、是否嵌入 |
| P2 | 封面信息 | 汇报人、课题组/学校、日期（答辩加导师、学号）？ | 占位符 | 封面、页脚 |
| P2 | 已有材料 | 有没有已有 PPT、组里往期汇报、导师偏好或必须保留的页？ | 无 | 继承版式或增量修改 |
| P2 | 动画 | 需要逐步出现的动画吗？还是每页静态？ | 静态，必要处用分页构建 | 构建页数量 |
| P2 | 交付 | 除了 PPTX，还要讲稿、PDF、逐字稿吗？截止时间？ | PPTX + 备注 + 预览图 | 交付物与节奏 |

**第一轮问 P0 全部 + P1 中最相关的 1–2 个；第二轮补齐剩余 P1；P2 可在 G2 大纲确认时一起问。**

## 2. 场景追问

只问与当前场景相关的。

### 组会读论文
- 需要“对我们组的启发 / 能否复现”页吗？（默认：要）
- 结尾要准备几个讨论问题？（默认：组会 2–3 个，学生课程展示 1–2 个）
- 组里有固定的汇报格式或页脚吗？
- 是否需要对比组里之前读过的相关论文？

### 会议 talk / 讲自己的论文
- 会议有官方模板、页数或比例要求吗？
- 时长是否包含 Q&A？
- 需要哪些备份页？（审稿意见里被问过的点最值得准备）
- 要放开源链接、二维码或作者头像吗？

### 答辩 / 开题 / 中期
- 学校标准色、校徽、指定模板？
- 学位论文共几章？每章对应哪篇已发表论文？
- 评委最可能关注什么？（工作量、创新点、某个实验）
- 需要“攻读期间成果”“致谢”页吗？成果按什么格式列？
- 开题：要不要技术路线图、进度安排、预期成果？中期：已完成/未完成/调整说明？

### 课程展示
- 课程名称与评分标准？
- 需要互动、提问或小测吗？
- 是小组展示吗？需要标注分工吗？

### 工作汇报 / 基金汇报
- 汇报对象（导师 / 领导 / 评审）？他们最关心进度、结果还是风险？
- 需要甘特图、进度表或预算吗？

## 3. 第一条消息范例

用户只说“帮我把这篇论文做成 PPT”时：

> 开工前确认几件事，回编号就行，不答的按默认：
> 1. 场景：组会读论文 / 讲自己的论文 / 答辩 / 课程展示 / 工作汇报？（默认：组会读论文）
> 2. 讲多细：简略约 10 页、8–10 分钟；详细约 18–20 页、15–20 分钟？（默认：详细）
> 3. 听众：同方向 / 同领域不同方向 / 外行或评委？（默认：同领域不同方向）
> 4. 语言：PPT 和备注都用中文？（默认：是）
> 5. 风格：有想用的预设、截图或学校模板吗？没有我按场景推荐。
> 6. 你最希望听众记住论文的哪一点？

用户说“帮我做 15 分钟中文组会汇报，风格 domestic”时（已给出时长、语言、风格、场景）：

> 收到。再确认三点：
> 1. 听众是同方向还是同领域不同方向？（默认：同领域不同方向）
> 2. 最想重点讲方法还是实验？有没有可以略过的部分？
> 3. 在自己电脑上放映，还是会场电脑？（影响字体，默认：会场 Windows）

用户说“你看着办，直接做”时：只问详略一句，其余用默认值，写进 `design-brief.md`。

---

## 4. 追问规则

- **含糊 → 具体化一次**：“重点讲方法” → “方法里最想讲细的是哪个模块？”；“简洁一点” → “页数控制在 10 页左右，还是每页字少一些？”
- **冲突 → 指出并让用户选**：“15 分钟但要讲全部 6 个实验，大约需要 25 页。是压缩到 3 个主实验，还是延长时间？”
- **读论文后的新分歧 → 放到 G2**：例如论文有两条贡献线、某个关键实验结果不清楚、图表质量太低需要重画。
- **不要问**：能从论文读出来的（作者、会议、年份）、与成品无关的偏好、已经回答过的问题。
