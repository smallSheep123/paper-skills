# PPT 视觉系统：公共规则 + 双风格路由

本文件只定义**所有风格共同遵守的底线**。具体视觉语言必须从以下二选一：

- [academic-clean.md](academic-clean.md)：学术简约 / Paper-faithful。默认用于组会、论文精读、答辩式汇报。
- [academic-rich.md](academic-rich.md)：学术丰富 / Conference-editorial。用于课程分享、公开演讲、希望更有演示感的技术汇报。
- 设计原则来源与蒸馏过程见 [academic-slide-distillation.md](academic-slide-distillation.md)。

> 重要：这些是给视觉 AI 的设计约束，不是给代码套模板。JS/Python 只负责把 AI 已经决定好的内容、图形和坐标落到 PPTX；不得用“自动套版/随机布局/卡片生成器”代替视觉判断。

## 0. 风格选择

用户明确指定时严格按用户选择。

用户没指定时：
- “组会 / 论文精读 / 忠实论文 / 正式答辩 / 简洁” → **academic-clean**
- “课程展示 / 公开演讲 / 好看一点 / 丰富一点 / 演示感” → **academic-rich**
- 不确定 → 默认 **academic-clean**，因为它更稳、更符合论文汇报。

两种风格可以共享内容结构，但**不能在同一 deck 中无规则混搭视觉语法**。Rich 可以借用 Clean 的克制页；Clean 不应突然出现营销式大卡片、渐变背景和装饰性插画。

## 1. 内容真实性：高于一切视觉效果

- 页面上的数字、结论、专有名词、实验设置必须可追溯到论文正文、图表或补充材料。
- 不确定的数字不写；视觉 AI 不得为了“完整”补造数据。
- 论文图不能改变其数据含义、坐标关系、图例含义或颜色编码语义。
- 自绘图只用于解释**结构、流程、对比、因果关系、读图路径**，不得伪装成论文实验结果。
- AI 生成图片若使用，只能作为概念性背景/章节视觉，不得作为实验、系统截图、数据证据。

## 2. 一页一个主消息

每页在生成前必须写出一条 `message`：
- 观众离开这一页时只需要记住什么？
- 这一页的标题、论文图、标注、文字都必须服务于它。

优先使用“结论型标题”：
- 弱：`实验结果`
- 强：`DVLA 在低迁移预算下仍显著减少 stranded machines`

但当用户要求严格对应论文章节时，可以保留正式章节式标题，并在副标题或结论带表达 message。

## 3. 视觉优先，文字只做支撑

- 先找“证据视觉”：论文图 / 表格重绘 / 系统图 / 数学关系 / 自绘机制图。
- 再写文字。禁止先写三段文字再想怎么装饰。
- 论文图若信息过载，要为演讲**裁剪、放大、重标注、拆页**，而不是整张截图缩小。
- 同一页通常只有 1 个主视觉；最多 2–3 个互相协作的视觉元素。
- 表格若只为了比较趋势，优先转为图、轴、矩阵或重点数字；若精确值本身重要才保留表格。

## 4. 字体与可读性

默认 Windows 可移植字体：
- 中文：**Microsoft YaHei / 微软雅黑**
- 英文与数字：**Arial**
- 全 deck 最多 2 个字族；不要混 Georgia、Times、花体、手写体。
- 正文建议 16–22pt；图注/来源 11–13pt；页标题 28–36pt。复杂原论文图里的文字若太小，应裁剪/放大，而不是把整图硬塞进去。
- 颜色对比要足够；不得只靠红/绿区分含义。

## 5. 图与论文的一致性

- 原论文图保持宽高比，不拉伸。
- 图注写清 Figure/Table 编号与来源；若做了裁剪/重绘，用“据 Figure N 重绘 / cropped from Figure N”说明。
- 优先保留论文原始视觉编码；如果为了讲解添加高亮，新增高亮必须明显是“讲解层”，不能混入数据层。
- 复杂图采用：**先整体 → 再局部 → 再结论**。必要时拆成两页。
- 视觉 AI 在排版前必须目检所有候选图片，不能只根据文件名或 caption 猜图。

## 6. 视觉 AI 检查点

视觉模型不是最后才来“挑错”，而要参与整个过程：

1. **素材目检**：判断每张论文图的内容、密度、可裁剪区域、是否适合演讲。
2. **Style brief**：根据用户场景 + 两套风格规范，确定视觉方向、密度、色彩、标题策略。
3. **Storyboard**：逐页决定 message / evidence / visual / layout，不写代码。
4. **2 页试制**：先做“最普通的一页 + 最复杂的一页”，渲染后交给视觉模型审美与可读性审核。
5. **全量生成**：代码只执行已经确认的视觉方案。
6. **逐页视觉验收**：检查信息层级、对齐、裁切、图像清晰度、论文一致性、AI 模板味。
7. **二次修订**：不是只修溢出；如果视觉模型判断一页信息组织不成立，应重排该页。

## 7. 共同禁区

- 禁止“3 个贡献卡片 / 4 个亮点卡片 / 每页圆角矩形堆叠”的默认 AI PPT 语法。
- 禁止大面积无意义渐变、霓虹、玻璃拟态、装饰线条、随机图标。
- 禁止把论文摘要拆成 bullet 后原样塞进 PPT。
- 禁止为了统一而强行每页相同布局。
- 禁止演讲稿上页面。
- 禁止在结果页用装饰性图片抢数据主视觉。
- 禁止代码自行决定设计。代码可以计算坐标、裁图、加注释、导出，但设计选择必须来自前面的 AI 视觉规划。
