# 排版与用色硬规则

统一的是**字体、颜色、页边距**；不统一的是**布局**（九页九个版式，别每页复制同样的圆角框）。

## 配色（BACKGROUND → PRIMARY → ACCENT）

- BACKGROUND：内容页纯白 `FFFFFF`；封面/结尾页深色（深蓝 `142438` 或深青 `0F2A31`），形成三明治。
- PRIMARY（60–70% 视觉权重）：深蓝 `1F3A66` 或深青 `0E5464`——标题、结构框、示意图主色。
- ACCENT（5–10%）：橙 `D2622A` 或赭 `BF4B18`——**只用于关键数字和问题句**，不做装饰条。
- 辅助：TEXT `232A31`、MUTED `66707A`、浅 tint 带 `EDF2F8`/`EEF4F4`、发丝线 `D9E0E8`。
- 禁止：彩虹配色、每页换色、奶油色背景、色块/accent 条/标题下划线（AI 味标志）。

## 字体

- 中文正文与标题：**微软雅黑**（Windows 必有，勿用仅构建机有的字体）。
- 数字与英文强调：**Arial 粗体**。禁用 Georgia——它的老式数字高低不齐，用户明确批评过。
- 全 deck ≤2 个字族；层级靠字号+字重。最小字号 ≥12pt（图注/页码/来源行也是）。
- 页标题 26–30pt，副标题 13–14pt MUTED，正文 13–16pt，大数字 17–28pt，封面主标 33–54pt。

## 布局

- 页边距 0.6"，内容块间距 0.3–0.5" 全篇一致。
- 版式逐页变化：非对称双栏 / 上下两层 / 大图+注释行 / 自绘流程 / Before-After / 左右结论页。
- 左对齐正文；只有问题句、Thanks 可居中。
- 强调"容器靠排不靠框"：分组用间距/发丝线/浅 tint 通栏，不用圆角卡片堆；卡片间不用边条。
- 一页一个焦点；删到"少而不空"——大空白用内容（大数字、图、结论带）解决，不用装饰填。

## 论文图与自绘图

- 论文图保持宽高比（按 AR 手算 w/h），配 12pt 图注 `Figure N — 中文说明（Zhang et al., OSDI'26）`。
- 必须保清两张大图：架构图、主实验图。其余图宁小勿缺。
- 概念示意优先自绘（如 VM 调度的 [L]=深蓝长VM / [S]=浅蓝短VM / 空位=白底描边方块行；
  流程=圆角矩形+三角箭头线；对比=左右两组方块）。自绘风格与配色继承 deck 调色板。
- 图里碎掉的图例/子图拼接缝：裁掉碎图例，用一行 12pt 文字图例替代。

## 数字与专有名词

- 页面上的每个数字都要能从论文正文找到出处；标注设置（如 "ChatBot，Qwen3-30B"）。
- 大数字 callout：数值 ACCENT 粗体 + 小标签 MUTED。
- 中英混排行里，英文术语跟随中文字体（雅黑拉丁字形），只有"数字强调"单独用 Arial 粗体。
