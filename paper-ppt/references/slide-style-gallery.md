# 学术 Slide 风格蒸馏库

> 来源：实际下载并渲染了下列公开 deck，逐页看图后提炼。  
> 用途：给视觉 AI 一份**可执行的版式手法清单**，而不是可套用的模板。  
> 与 [academic-slide-distillation.md](academic-slide-distillation.md) 的分工：那份讲“为什么清楚”，这份讲“具体怎么做”。  
> 可直接调用的实现见 [../styles/](../styles/README.md)（token、页面原型、示例页、参考截图）。

## 0. 观察样本

| # | Deck | 场景 | 最值得学的一件事 |
|---|------|------|------------------|
| A | Kaiming He，*Towards End-to-End Generative Modeling*（CVPR 2025 Tutorial） | 海外顶会 tutorial | 白底极简；公式上用彩色手写式圈注解释每一项 |
| B | Chris Ré，NeurIPS 2023 Keynote | 海外 keynote | 每页底部一个**红/蓝描边结论框**，一句话收束 |

| G | 李宏毅，一堂課看懂語言模型內部運作（NTU 2025） | 中文课程/讲座 | 一套固定的自绘图形“词汇”在全稿中反复使用 |

只提炼手法，不继承各自的学校配色、Logo、页脚品牌和字体文件。

## 1. 高频手法（按出现频率排序）

### P1. 标题 = 结论 / 问题，而不是章节名

- A：`Recognition vs. Generation: Two Sides of the Same Coin?`
- F：标题直接写技术判断，并把判断里的关键词（如“大模型”）标红

**做法**：标题写成一句完整判断或问题；中文 14–24 字为宜，超过就把限定条件挪到副标题。

### P2. 增量构建：同一张图连续多页，只变一处

- A：History 页先灰显整条 pipeline，下一页只把当前讨论的模块变实；
- D：Seq2Seq → Seq2Seq **with Attention** → Image Captioning with **Attention**，标题新增词标红，图中新增模块也用同一个红色。

**做法**：复杂方法拆成 2–4 页 overview → zoom-in；非当前部分统一降到 30–40% 灰度，不删除，保持空间记忆。

### P3. 一页一个“结论框”

- B：几乎每页底部一个单行描边框（红框 = 结论，蓝框 = 机制要点）；
- E：黄色底色块写这一页的定义或结论；被推翻的旧假设直接打红叉。

**做法**：结论框最多一行半，放在视线终点（底部或右下）；全稿颜色语义固定：一种颜色只表示一种含义。

### P4. 公式讲解层

- A：在公式上用彩色细线圈出某一项，旁边写 `average velocity` / `instantaneous velocity`；用删除线 + 红色箭头表示“我们实际做的替换”；
- A：代码页只给变化的那两行加浅紫底色，旁注 `the main changes over Flow Matching`。

**做法**：公式只留理解方法必需的一两行；讲解层（圈注、箭头、短标签）与公式本体颜色区分，标签 ≤ 4 个词。

### P5. 文字骨架三段式

- C：`Goal:` / `Challenge:` / `Our Solution:` 各一行，下面一张大图。

**做法**：适合“一篇论文一页”的综述式汇报和组会开场的 related work 速览；三行全部 ≤ 1 行，粗体只用于冒号前的标签。

### P6. 论文出处标签

- C/F/E：标题右上或条目后用小字标 `[ICLR'24 Oral]`、`[微软, ICLR2021]`、`[w/ Kleinberg-Faloutsos, KDD'05]`。

**做法**：12–14 pt 灰色或主色浅色；统一格式 `[机构/作者, 会议年份]`，全稿位置一致。

### P7. 研究问题编号导航

- E：`Q1)` … `Q9)` 研究问题编号贯穿全稿，进入每页标题；
- F：`技术进展一：…` … `技术进展五：…`，开头一页列出全部条目。

**做法**：超过 12 页或超过 3 个贡献点时使用；编号前缀进入标题，而不是另做目录页反复插入。

### P8. 结果页只标一个数

- A：ImageNet 表格保持论文原样，只在最后一行旁用红字写 `1-NFE: 70% improvement`；
- B：图表旁只放一个描边结论框说明“这张图说明了什么”。

**做法**：结果页的强调只给“会改变听众结论”的那一个数；直接标注优先于图例。

### P9. 统一的自绘图形词汇

- D：同一讲里张量/向量始终用同色小方块阵列表示；
- G：token、模型、层的画法在整套 slides 中反复复用，听众看一次就认识。

**做法**：第一张方法图定下 3–5 种基本图元（数据、模块、操作、注意力、损失），后续页面只复用、不新造。写入 design-brief 的“自绘图策略”。

### P10. 节奏页

- C：章节页 = 白底 + 居中大号主色文字，一句话（`New Architecture, New Primitives`）；
- B/G：关键问题页 = 一张大图 + 一句问题（`How efficient can we make current models?`）。

**做法**：每 5–8 页插一张节奏页；节奏页不放任何正文 bullet。

### P11. 致谢人而不是写 Thank You

- B：讲到某工作时直接放学生头像 + 名字；
- C：结尾放团队合照 + 代码/主页链接。

**做法**：组会汇报他人论文时，在封面或方法页小字标注第一作者与机构即可；结尾放“结论 + 局限 + 讨论问题”，不单独做 Thank You 页（国内场景见 §3 例外）。

## 2. 海外组会 / 会议风格（International）

对应样本 A–E。

| 维度 | 取值 |
|------|------|
| 背景 | 纯白；封面可白可深色 |
| 标题 | 左上对齐，黑色或单一主色，28–36 pt，一句结论/问题 |
| 正文 | 每页 ≤ 3 条 bullet，每条 ≤ 1 行；大量页面没有 bullet |
| 色彩 | 黑 + 1 个强调色（常见红或蓝），强调色只用于“新内容/结论/自家方法” |
| 图文比 | 图 ≥ 60% 面积 |
| 导航 | 研究问题编号（P7）或增量构建（P2），较少用目录页 |
| 页脚 | 可选：细色条 + 讲者 · 题目 · 页码；不放 Logo 墙 |
| 结尾 | Looking ahead / Open questions，用问题收尾 |

适合：英文汇报、海外组会、投稿前 rehearsal、跨组 reading group。

## 3. 国内组会 / 学术报告风格（Domestic）

对应样本 F、G，以及国内高校组会常见规范。

| 维度 | 取值 |
|------|------|
| 背景 | 白底；封面常居中排版：题目 / 汇报人 / 单位 / 日期 |
| 标题 | 左上，主色小方块或竖条 + 主色加粗标题；**标题内关键词用强调色（常为红）** |
| 正文 | 中文短句，层级 2 级以内；关键词红字；条目后带出处小字（P6） |
| 色彩 | 主色深蓝 / 学校色之一 + 红色强调 |
| 图文关系 | 论文图常配浅灰圆角框 + 下方中文小标题（如“拼图游戏”“自编码器”） |
| 导航 | “一、二、三”或“技术进展一：”式标题前缀（P7），开头一页列提纲 |
| 中英混排 | 方法名、数据集、指标保留英文；解释性文字用中文 |
| 结尾 | 总结 + 下一步工作；“谢谢大家 / 恳请批评指正”页可保留，但不超过一页 |

国内组会常见的额外期待：

1. 封面写清**论文题目（原文）+ 会议/期刊 + 作者单位**；
2. 第 2 页给**汇报提纲**；
3. 每篇论文先交代**动机 → 方法 → 实验 → 个人思考/与本组工作的联系**；
4. 最后一页给**可讨论的问题**，方便导师提问。

## 4. 两种风格都不要做

- 每页都加 Logo 墙、学校水印或大面积页脚；
- 把论文整页截图缩小当一页；
- 同一页出现三种以上强调色；
- 用阴影/渐变卡片包装每一个 bullet；
- 红色强调泛滥到每行都有。

## 5. 视觉 AI 自检清单

1. 标题能否单独读成一句话？（P1）
2. 复杂方法是否拆成增量页？（P2）
3. 每页是否有且只有一个视线终点？（P3/P8）
4. 公式与讲解层颜色是否分开？（P4）
5. 自绘图元是否全稿复用？（P9）
6. 出处标签格式与位置是否一致？（P6）
7. 是否每 5–8 页有一张节奏页？（P10）
8. 选用的海外/国内风格，是否在 design-brief 中写明？
