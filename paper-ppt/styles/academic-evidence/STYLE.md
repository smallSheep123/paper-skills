# Academic Evidence：学术证据讲解风格

这是一份可选的风格说明，来自 The Interaction Tax 汇报的迭代经验。中英文 PPT 是同一个风格系列的两个案例，不代表“中文/英文汇报就应该长这样”，也不覆盖其他九套预设。本目录不注册新的固定模板；AI 选择该风格后，结合论文内容重新构图。

## 适用范围与取舍

适合需要逐步解释方法、核对实验条件、讨论结果边界的论文精读和组会。倾向于白底、较克制的配色、就近解释和较少的装饰；因此原图和数据容易成为焦点，但未必适合需要强烈品牌表现的发布会，也不追求理论讲义的高密度。

这些是本风格的偏好。需要强烈节奏时可选 Keynote Minimal，需要完整证明时可选 Theory Beamer，需要正式章节导航时可选 Defense CN。可读性与证据正确性仍需实际核验，不能由风格名字保证。

## 设计判断与可调整项

| 选择 | 本风格为什么这样做 | 何时调整 |
|---|---|---|
| 白底、有限强调色 | 把注意力放在论文证据和解释上 | 用户品牌、场地或参考图要求深色时另选/改配色 |
| 图与说明就近放置 | 减少听众在整页寻找解释的距离 | 多实验比较可采用矩阵、整页表格或连续页 |
| 每页一个主要判断 | 适合逐步口头讲解 | 成对估计、敏感性分析需要同时保留多个值 |
| 较少独立转场 | 短组会留更多时间讲证据 | 长报告、答辩可增加章节停顿 |
| 原图比例决定可用文字区 | 方图、竖图和横图需要不同空间 | 可以换栏位和裁切局部；裁切需保留必要标签 |
| 标题表达观察或问题 | 听众容易跟住讲述 | 概念定义、推导和概览页也可用简短主题标题 |

本次中英文案例借用了 Domestic / International 的标题和导航语言，但对图片宽度、结果标注和转场做了当次调整。它们不修改那两套预设本身。

16:9 投影可从正文 20–24 pt、主公式 26–32 pt、图表标签 17–18 pt 起步。这是案例的起始值，不是通用工具的字号下限。关键说明读不清时，本风格通常先减内容、换构图或拆页；其他风格可以选择不同密度。

在构图不确定时，可比较整图注释与图文分栏等两种方案；不要求每次固定做两版。比较时说明证据完整性、阅读顺序和适用场景，不能仅用“更高级”“更好看”作为理由。

## 公式页示例

`equation-layout.js` 是本风格的可选排版示例：公式居中，解释放在下面，按实际高度保留间距。坐标、说明位置和行数不属于公共公式工具的规定。

通用公式接口见 [math-equations.md](../../references/math-equations.md)：所有风格都可以使用 `addEquation()` / `canvas.equation()`，自行传入位置、字号和颜色。运行 `npm run math-samples` 可重建本风格的中英文公式样页；不意味着其他风格采用相同布局。
